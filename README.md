# Nacht Reborn Booster

Native Android prototype using Kotlin and Jetpack Compose.

Included in this starter:
- Dark silver dashboard
- Android overlay permission flow
- Draggable floating bubble with an expandable quick panel
- App-permissions shortcut
- Basic spoken introduction using Android Text-to-Speech
- GitHub Actions workflow to build and upload a debug APK artifact

Not implemented yet: secure login, cloud backend, premium billing/entitlements, ZIP inspection/extraction, favorites/history, connected AI instructor, production diagnostics, and game-specific integrations. The app does not claim to increase FPS or bypass Android/game restrictions.

The workflow is in .github/workflows/android-apk.yml.
